# Choreit ✅

Choreit is a **mobile-friendly, iOS-optimized chore app** that combines:
- task management
- social motivation
- gamification
- privacy-first local storage

The experience is designed to feel app-like, with a **green primary UI theme**, touch-first controls, and a homepage that includes quick action buttons to instantly add:
- Washer done
- Dryer done
- Dishwasher done

---

## ✨ Core Experience

- **Priority chore lists** (high / medium / low)
- **Progress tracking** (history, streaks, weekly stats)
- **Social feed** (household and public sharing, likes, comments, celebration posts)
- **Gamification** (badges, streaks, leaderboard, encouraging messages)
- **PWA support** (offline-capable + installable)
- **Browser local storage only** (data stays on-device)
- **Modern responsive UI** optimized for phones and iOS “Add to Home Screen”

---

## 🚀 Quick Local Run (One-Liner)

If Node.js is installed, run this from the project folder:

```bash
npx serve . -l 4173
```

Then open: `http://localhost:4173`

---

## 🛠️ Setup (Step-by-Step)

1. Install [Node.js LTS](https://nodejs.org/)
2. Open a terminal in this repository
3. Start local hosting:
   ```bash
   npx serve . -l 4173
   ```
4. Visit `http://localhost:4173` on desktop or mobile browser
5. On iPhone/iPad (Safari): **Share → Add to Home Screen** for app-like usage

## 📱 Product Goals

Choreit should make household chores feel social, rewarding, and consistent by blending:
- fast chore capture
- friendly accountability
- progress visibility
- celebration of wins

The goal is to help users **do more chores more often** while making the process genuinely fun.
